# أحمد العلي TV — GitHub Pages

## الملفات
- `index.html`: صفحة الموقع.
- `ahmed-alali-tv-1.3.apk`: ملف التطبيق الذي زودني به صاحب الموقع.

## النشر على GitHub Pages
1. سجّل الدخول إلى https://github.com
2. أنشئ مستودعًا جديدًا (New repository)، مثل `ahmed-alali-tv`.
3. ارفع الملفين الموجودين في هذا المجلد إلى جذر المستودع.
4. افتح Settings → Pages.
5. تحت Build and deployment اختر Deploy from a branch.
6. اختر الفرع `main` والمجلد `/(root)` ثم Save.
7. انتظر حتى يظهر رابط الموقع في صفحة Pages. غالبًا يكون:
   `https://USERNAME.github.io/ahmed-alali-tv/`
   استبدل `USERNAME` باسم حسابك الحقيقي.
8. افتح رابط الموقع وجرب زر تحميل APK.

## ملاحظات
- هذا مجلد جاهز للرفع إلى GitHub Pages، لكنه لم يُنشر تلقائيًا لأن ذلك يتطلب الدخول إلى حساب GitHub الخاص بك.
- إذا ظهر رفض بسبب حجم ملف APK أو سياسة المستودع، ارفع APK إلى خدمة استضافة ملفات مناسبة، ثم عدّل متغير `APK_URL` في `index.html` إلى رابط التنزيل المباشر.
- لا ترفع ملفات لا تملك حق توزيعها، وتأكد من سلامة APK وصلاحياته قبل نشره.
