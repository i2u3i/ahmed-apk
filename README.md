# أحمد العلي TV — موقع جاهز لـ GitHub Pages

## محتويات المجلد
- `index.html` — موقع عربي بتصميم CSS مدمج وخط Cairo وفلاتر JavaScript.
- `ahmed-alali-tv-1.3.apk` — ملف APK الذي أرسله صاحب التطبيق.

## النشر
1. أنشئ مستودعًا عامًا جديدًا على https://github.com (مثال: `ahmed-alali-tv`).
2. ارفع الملفين مباشرة إلى جذر المستودع، وليس داخل مجلد فرعي.
3. افتح Settings → Pages.
4. اختر Deploy from a branch، ثم الفرع `main` والمجلد `/(root)` واضغط Save.
5. انتظر رابط GitHub Pages الظاهر في نفس الصفحة، ثم افتحه واختبر زر APK.

ملاحظات:
- الموقع لم يُنشر تلقائيًا؛ يلزم رفع الملفات إلى حساب GitHub الخاص بك.
- خط Cairo يأتي من Google Fonts ويحتاج الإنترنت، مع وجود خطوط بديلة.
- إذا تعذر رفع APK إلى المستودع، استضف الملف في مكان مناسب وعدّل روابط `./ahmed-alali-tv-1.3.apk` في `index.html`.
